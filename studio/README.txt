ZBOOK STUDIO - EARLY PROTOTYPE

Files:
- index.html: open in a modern browser (Chrome, Edge, Firefox, Safari).
- sample-book.zbook: sample ZBOOK JSON book.

Features:
1. Book Creator: make books with chapters, embedded images and audio narration.
2. Reader: open ZBOOK files and display text, pictures and audio.
3. PDF Converter: extracts selectable text from PDF pages into chapters. Requires internet to load Mozilla PDF.js from cdnjs. It does not OCR scanned PDFs or preserve exact PDF layout.
4. Validator: checks basic ZBOOK structure. It is not a complete JSON Schema validator.

All processing is local in your browser. No server or account is required.
The proposed format and media type are drafts, not an approved IANA standard.
The built-in creator attribution says Surya Prakash V; metadata is not cryptographic proof of authorship.

To run:
1. Extract this ZIP.
2. Open index.html in a current browser.
3. For PDF conversion, connect to the internet.
