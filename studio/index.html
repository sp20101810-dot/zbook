PDF to ZBOOK converter

Select a text-based PDF. Each PDF page becomes a ZBOOK chapter. Scanned/image-only PDFs may produce little or no text and need OCR, which this prototype does not provide.

PDF conversion uses Mozilla PDF.js loaded from a public CDN, so an internet connection is required for this feature.
